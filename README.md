# e-Learning-CAI
คู่มือการพัฒนาระบบและการใช้งานเว็บแอปพลิเคชันเพื่อการศึกษา (e-Learning CAI)
รายวิชาวิทยาการคำนวณ (ว21101) ระดับชั้นมัธยมศึกษาปีที่ 1 | โรงเรียนบ้านแมดนาท่ม

แพลตฟอร์มนี้ถูกพัฒนาขึ้นในรูปแบบ Single-Page Application (SPA) เพื่อเป็นสื่อการเรียนการสอนดิจิทัลที่ออกแบบมาสำหรับบริหารจัดการชั้นเรียนขนาด 60 คน โครงสร้างสถาปัตยกรรมเน้นการทำงานแบบรวดเร็ว โหลดง่าย และผสานการจัดเก็บข้อมูลอย่างปลอดภัยผ่านระบบคลาวด์ของ Supabase

🌟 ความสามารถและจุดเด่นของระบบ (System Capabilities)
ระบบบริหารจัดการสิทธิ์ (Role-Based Access Control):

👩‍🎓 พื้นที่ผู้เรียน (Student Portal): ให้นักเรียนสามารถเข้าศึกษาเนื้อหา รับชมสื่อมัลติมีเดีย อัปโหลดหลักฐานการส่งแบบฝึกหัด จัดการข้อมูลส่วนตัว และมีแถบแสดงความก้าวหน้า (Progress Bar) เพื่อประเมินตนเอง

👨‍🏫 ระบบจัดการหลังบ้าน (Instructor Panel): แดชบอร์ดสำหรับครูเพื่อมอนิเตอร์ภาพรวมของนักเรียนทั้ง 60 คนแบบ Real-time ตรวจสอบสถิติการเรียน และเช็คคิวภาระงานที่รอการตรวจให้คะแนน

ระบบทดสอบเสมือนจริง (Sandbox / Mock Mode): ฟังก์ชันพิเศษที่ช่วยให้นักพัฒนาหรือผู้สอนสามารถเปิดทดสอบหน้าตาของเว็บ (UI) ได้ทันที โดยมีชุดข้อมูลสมมติ (Dummy Data) ทำงานอยู่เบื้องหลัง ไม่จำเป็นต้องเชื่อมต่อเซิร์ฟเวอร์จริงก็สามารถดูระบบได้

ประสบการณ์การใช้งาน (UX/UI): ออกแบบเลย์เอาต์แบบ Responsive รองรับการแสดงผลทุกสัดส่วนหน้าจอ ทั้งหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน

🛠️ สถาปัตยกรรมและเครื่องมือการพัฒนา (Technology Stack)
Frontend (ฝั่งหน้าบ้าน): โครงสร้างหลักเขียนด้วย HTML5, ควบคุมลอจิกด้วย Vanilla JavaScript, จัดการความสวยงามผ่าน Tailwind CSS (ใช้งานผ่านระบบ CDN) และตกแต่งด้วยชุดไอคอนจาก Lucide Icons

Backend & BaaS (ฝั่งหลังบ้าน): ขับเคลื่อนข้อมูลด้วยแพลตฟอร์ม Supabase ซึ่งครอบคลุมระบบฐานข้อมูล (PostgreSQL), ระบบยืนยันตัวตน (Auth) และพื้นที่ฝากไฟล์ (Storage)

🗄️ พจนานุกรมข้อมูล (Database Schema)
โครงสร้างการจัดเก็บข้อมูลเบื้องต้นบนระบบ PostgreSQL มีดังนี้:

profiles: ตารางจัดการข้อมูลบัญชีผู้ใช้ ระบุบทบาท (นักเรียน/ครู) รหัสประจำตัว และเชื่อมโยงกับระบบรักษาความปลอดภัย Auth

lessons: คลังจัดเก็บข้อมูลรายวิชา โครงสร้างบทเรียน และลิงก์สำหรับวิดีโอ

assignments: พื้นที่เก็บข้อมูลภารกิจ โจทย์ปัญหา และแบบทดสอบของแต่ละหน่วย

submissions: บันทึกประวัติการส่งงานแนบไฟล์ สถิติ และสรุปผลคะแนน

⚙️ คู่มือการติดตั้งและการนำขึ้นระบบ (Deployment Workflow)
หากต้องการสลับจาก "โหมดจำลอง" ไปสู่ "ระบบจริง" ให้ปฏิบัติตามขั้นตอนต่อไปนี้:

Step 1: การเตรียมพร้อมฝั่งเซิร์ฟเวอร์ (Supabase Setup)

ลงทะเบียนและสร้างโปรเจกต์ใหม่ผ่านแพลตฟอร์ม Supabase

ไปที่เมนู SQL Editor ทำการคัดลอกสคริปต์จากไฟล์ schema.sql มาวางแล้วกดปุ่ม Run (ขั้นตอนนี้ระบบจะสร้างตารางข้อมูลทั้ง 4 พร้อมเปิดระบบรักษาความปลอดภัย RLS อัตโนมัติ)

ไปที่เมนู Storage และทำการสร้าง Buckets ใหม่จำนวน 2 โฟลเดอร์ (กำหนดสิทธิ์เป็น Public) ได้แก่:

โฟลเดอร์ avatars (สำหรับอัปโหลดรูปประจำตัว)

โฟลเดอร์ assignments (สำหรับจัดเก็บไฟล์งานของนักเรียน)

Step 2: การคอนฟิกฝั่งหน้าบ้าน (Frontend Configuration)

เปิดไฟล์ cai_app.html ในโปรแกรม Code Editor ของคุณ (เช่น VS Code)

เลื่อนไปที่บรรทัดประมาณ 225 เพื่อค้นหาบล็อก <script>

นำค่า API จากโปรเจกต์ของคุณ (ดูได้ที่ Supabase -> Project Settings -> API) มาแทนที่ในชุดโค้ดดังนี้:

JavaScript
const SUPABASE_URL = 'https://[รหัสโปรเจกต์ของคุณ].supabase.co'; 
const SUPABASE_ANON_KEY = '[รหัส API KEY ของคุณ]';
(💡 ทริค: ทันทีที่คุณอัปเดตคีย์ของจริงเสร็จ ระบบจะตัดการทำงานของ Mock Mode ทิ้ง และสลับไปเชื่อมโยงกับฐานข้อมูลจริงโดยอัตโนมัติ)

Step 3: การเผยแพร่แอปพลิเคชัน (Web Hosting)
สถาปัตยกรรมของระบบนี้รวบรวมทุกอย่างไว้ในไฟล์ HTML ตัวเดียว คุณจึงสามารถนำไฟล์ cai_app.html ไปอัปโหลดขึ้นโฮสติ้งฟรีเพื่อใช้งานจริงได้ทันที แพลตฟอร์มที่แนะนำ ได้แก่ Vercel, Netlify หรือ GitHub Pages
