# e-Learning-CAI
🚀 CAI WebAR Courseware: ระบบคอมพิวเตอร์ช่วยสอนผสานเทคโนโลยีความจริงเสริม
รายวิชาวิทยาการคำนวณ ว25101 | โรงเรียนเต่างอยพัฒนะศึกษา
แพลตฟอร์มการเรียนรู้ออนไลน์ที่ถูกพัฒนาขึ้นในรูปแบบ Single-Page Application (SPA) ผสานเทคโนโลยีความจริงเสริม (Augmented Reality) ผ่านเว็บเบราว์เซอร์ ออกแบบมาเพื่อเพิ่มประสิทธิภาพการจัดการเรียนการสอนและประเมินผลผู้เรียนอย่างเป็นระบบ

📌 1. Project Overview & Key Features (ภาพรวมและฟีเจอร์การทำงานหลัก)
ระบบถูกออกแบบให้รองรับการใช้งาน 2 ระดับ (Role-based) ได้แก่ ผู้เรียน (Student) และ ผู้สอน (Teacher) โดยมีฟีเจอร์เด่นดังนี้:
-ระบบสลับชุดข้อสอบคู่ขนานอัตโนมัติ (Parallel Exam System): จัดสรรชุดข้อสอบ (ชุด A / ชุด B) สำหรับก่อนเรียนและหลังเรียนแบบสลับกันอัตโนมัติ โดยคำนวณจากเลขคี่และเลขคู่ของรหัสนักเรียน 11 หลัก
-เส้นทางการเรียนรู้ (Learning Roadmap): แถบติดตามความก้าวหน้า 5 หน่วยการเรียนรู้ พร้อมระบบปลดล็อกเนื้อหาถัดไปอัตโนมัติเมื่อผู้เรียนส่งงานสำเร็จ
-สื่อปฏิสัมพันธ์ 3 มิติ (WebAR): แสดงผลโมเดล 3 มิติ (เช่น โมเดลนักบินอวกาศ) ที่สามารถหมุน ซูม และรองรับการเปิดกล้องสมาร์ตโฟนเพื่อดูโมเดลในพื้นที่จริง (AR) ได้ทันที
-ระบบปรับขนาดรูปภาพฝั่งผู้ใช้ (Client-Side Image Resize): ใช้เทคโนโลยี HTML Canvas เพื่อย่อขนาดรูปภาพโปรไฟล์ให้ไม่เกิน 400x400 px ก่อนบันทึก เพื่อลดภาระพื้นที่จัดเก็บ
-ระบบส่งงานปฏิบัติการ (Assignment Submission): รองรับการอัปโหลดไฟล์งาน (สูงสุด 20MB) หรือแนบลิงก์ผลงานจากแพลตฟอร์มภายนอก
-แดชบอร์ดอัจฉริยะสำหรับผู้สอน (Teacher Dashboard):
      -ประเมินผลสัมฤทธิ์ทางการเรียนด้วยสูตรคำนวณ ดัชนีประสิทธิผล (Hake's Normalized Gain) อัตโนมัติ พร้อมกราฟแท่งเปรียบเทียบคะแนน
      -ระบบส่งออกข้อมูลคะแนนเป็นไฟล์ CSV (รองรับภาษาไทยด้วย UTF-8 BOM)
      -ระบบจัดการคลังสื่อการสอน (Materials) และคิวตรวจงานนักเรียน

📁 2. Project Structure (โครงสร้างไฟล์และโฟลเดอร์)
        เนื่องจากโปรเจกต์นี้ถูกออกแบบเป็น Serverless Single-Page Application โครงสร้างจึงมีความเรียบง่ายและสามารถทำงานได้สมบูรณ์ในไฟล์เดียว:
              .
              ├── index_2.html         # ไฟล์หลักของระบบ (รวบรวม HTML, CSS, JavaScript และ UI ทั้งหมด)
              ├── README.md            # เอกสารคู่มือและข้อมูลทางเทคนิคของโปรเจกต์
              └── assets/              # (โฟลเดอร์เสริมหากมีในอนาคต สำหรับเก็บไฟล์รูปภาพ หรือโมเดล 3D แบบ Local)

🛠️ 3. Tech Stack & Database Schema (เทคโนโลยีและโครงสร้างข้อมูล)
        เทคโนโลยีฝั่งหน้าบ้าน (Frontend Tech Stack):
         -Core: HTML5, JavaScript (ES6)   
         -Styling: Tailwind CSS (ผ่าน CDN)   
         -Typography & Icons: Google Fonts (Sarabun), Lucide Icons   
         -3D/AR Engine: Google <model-viewer> v3.4.0 (รองรับ WebXR, Scene Viewer, Quick Look)   
สถาปัตยกรรมข้อมูลจำลอง (Mock Data Schema):
ปัจจุบันระบบทำงานในโหมดจำลองสถานการณ์ (Mock Mode) โดยมีโครงสร้างข้อมูลเบื้องต้นดังนี้:
  -Users / Students: เก็บข้อมูลรหัสนักเรียน 11 หลัก, ชื่อ-นามสกุล
  -Scores: เก็บข้อมูลคะแนน Pre-test และ Post-test (เต็ม 10 คะแนน) เพื่อนำไปคำนวณค่า Gain (g)
  -Progress: เก็บสถานะหน่วยการเรียนรู้ปัจจุบัน (1-5)
🚀4. Quick Start Guide (คู่มือการติดตั้งและการนำขึ้นระบบ)
แอปพลิเคชันนี้ไม่ต้องการการตั้งค่าเซิร์ฟเวอร์ที่ซับซ้อน สามารถเริ่มต้นใช้งานได้ทันที:
วิธีที่ 1: การรันเพื่อทดสอบบนเครื่องส่วนตัว (Local Development)
1.ดาวน์โหลดไฟล์ index_2.html ไว้ในเครื่องคอมพิวเตอร์ของคุณ   
2.ดับเบิลคลิกเปิดไฟล์ด้วยเว็บเบราว์เซอร์ (แนะนำ Google Chrome หรือ Microsoft Edge)   
3.ระบบจะทำงานในโหมดจำลอง (Mock Mode) ได้ทันทีโดยไม่ต้องใช้อินเทอร์เน็ต (ยกเว้นการโหลดไฟล์ AR และ CSS จาก CDN)   
วิธีที่ 2: การนำขึ้นโฮสติ้งจริง (Production Deployment)
นำไฟล์ index_2.html ไปอัปโหลดผ่านผู้ให้บริการ Static Hosting ฟรี เพื่อแจกจ่ายลิงก์ให้นักเรียนเข้าใช้งาน เช่น:
  -GitHub Pages: อัปโหลดไฟล์ขึ้น Repository และเปิดใช้งานโหมด Pages
  -Vercel / Netlify: ลากไฟล์ไปวาง (Drag & Drop) ในหน้า Deploy ของระบบได้ทันที
